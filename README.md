A program that writes one short text to intrigue the AI judge reading it: a gardener, a seed that flowers only once at night, and an invitation to stay up and see it.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the output directory).
